# 我的资产静态页面

参考 [Figma 节点 31040:4380](https://www.figma.com/design/NVwAAv12WZx1LiCTqPMNWD?node-id=31040-4380)。顶部复用 `BusinessPageHero`，资产预览及六条收支明细使用 `src/mock/asset.ts`；余额为 `8,864.980324 disco`，收入/支出分别使用原设计中的绿色/紫色图标和金额。

提取按钮使用现有主按钮皮肤，打开共享 `ConfirmPopup` 展示可提取余额，确认仅关闭，不调用接口、钱包或合约，也不修改余额。设计稿中的禁用术语已按 `PROJECT_TERMS.md` 统一为“提取”。不注册虚假下拉刷新。

六份资源已从 Figma 下载到 `src/assets/asset/`。五张位图按实际显示尺寸保留足够清晰度后转为 WebP，原始内容及裁剪比例不变；提取 SVG 保持原始字节及 32×32 根尺寸。章节星复用公共资源，Hero 叠层沿用既有 435×240 SVG。资源总大小从 8,301,883 bytes 减至 307,527 bytes，约减少 96.3%。

三种启用语言均补齐文案；长文案允许资产操作行换行。保持已固定 Header、菜单、Logo、语言开关及主题，页面视觉和交互验收由开发者负责。
