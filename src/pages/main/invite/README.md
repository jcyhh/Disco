## 本地交互

- 邀请码及完整有效邀请链接使用共享 `copyTextToClipboard()`，仅在实际复制成功后显示成功提示，失败可手动选取复制。
- 保存海报调用 `poster.ts`，用本地背景、宝箱、分隔饰和当前语言文字、邀请码、完整邀请链接合成 PNG。不是网页截图，不依赖上传服务或外部渲染接口。
- 生成后通过现有 Popup 展示预览和真实下载链接；移动端也可长按预览图保存。海报链接在替换和组件卸载时释放，生成失败有提示。海报不绘制页面上无分享意义的复制或保存按钮。
- 海报支持译文及邀请链接换行，完整链接不会被截断；页面链接行使用省略号且可复制完整值。

所有可见文案使用 `t()`；页面视觉和交互验收由开发者负责。
