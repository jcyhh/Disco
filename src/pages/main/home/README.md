# 首页静态页面

`HomePage.tsx` 实现五个内容模块：顶部活动 Banner、公告、四个快捷入口、参与探索和认识 Disco。认识 Disco 包含发行概览与通缩比例。当前处于静态页面开发阶段，页面验收由开发者负责。

- Banner 使用默认水平方向的 `BasicCarousel`；公告使用 `direction="vertical"`，由首页样式设置固定高度。多条内容每三秒自动循环，交互后继续播放；空内容或单条内容关闭循环和自动播放。
- 快捷入口通过 `ROUTE_PATH` 跳转到激活卡、预约记录、我的资产和邀请好友对应的一级页面。
- 点击当前公告或同一条中的箭头，使用本地状态打开共享 `Popup`，关闭按钮清除选中公告。
- “立即预约”当前只跳转到预约记录，不提交预约或其他业务操作。

## 数据与资源

首页本地数据统一在 `src/mock/home.ts` 管理，并通过 `@/mock` 导入：三个 Banner 条目复用同一张活动图，公告使用不同文本；轮次、金额、激活卡消耗、日收益率、周期和发行概览均为静态展示值。联调时再替换数据来源。

页面专属切图放在 `src/assets/home/`。活动 Banner 运行时使用 `src/mock/assets/banner.webp`；大图使用 WebP，原始资源保留作为源文件。五张压缩资源合计从 3,715,915 bytes 降至 554,184 bytes，减少约 85.1%。USDT 图标统一通过 `@/assets/tokens` 的 `usdtIconUrl` 引用，后续页面复用该入口。

## 公共约定

首页复用 `BasicCarousel`、`Popup`、全局工具类和主按钮皮肤；页面几何与装饰样式位于 `HomePage.scss`。Header、左侧侧边栏、菜单、多语言开关、品牌和公共按钮默认样式维持已确认的基线。

保持 `.env.development` 的 `VITE_STATIC_PAGE_MODE = 1`，预览固定已登录。首页不发起接口、RPC、钱包登录或上传请求，也不以静态数据提交业务；预约记录已接入本地 mock，其余业务页面继续按静态页面开发流程实现。
