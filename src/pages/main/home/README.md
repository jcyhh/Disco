# 首页静态页面

`HomePage.tsx` 实现五个内容模块：顶部活动 Banner、公告、四个快捷入口、参与探索和认识 Disco。认识 Disco 包含发行概览与通缩比例。当前处于静态页面开发阶段，页面验收由开发者负责。

- Banner 使用默认水平方向的 `BasicCarousel`；公告使用 `direction="vertical"`，由首页样式设置固定高度。多条内容每三秒自动循环，交互后继续播放；空内容或单条内容关闭循环和自动播放。
- 快捷入口通过 `ROUTE_PATH` 跳转到激活卡、预约记录、我的资产和邀请好友对应的一级页面。
- 点击当前公告或同一条中的箭头，跳转到 `/notice` 公告列表；列表再进入 `/notice/:id` 阅读全文。
- 首页首次进入时，最新 mock 公告若未读即自动弹出 `HomeNoticePopup`。关闭或点击“查看详情”会按 `id + updated_at` 标记本会话已读，返回首页不再弹出同一版本；`sessionStorage` 不可用时在当前运行期间以内存兜底。
- “立即预约”当前只跳转到预约记录，不提交预约或其他业务操作。

## 数据与资源

首页本地数据统一在 `src/mock/home.ts` 管理，并通过 `@/mock` 导入：三个 Banner 条目复用同一张活动图，公告栏取 `src/mock/notice.ts` 的前三条；轮次、金额、激活卡消耗、日收益率、周期和发行概览均为静态展示值。公告弹窗、列表和详情共用同一份公告数据，正文按纯文本安全渲染且不作为 UI 文案翻译。联调时再替换数据来源。

公告只参考 AIGO 的数据协议；AIGO 没有可迁移的公告 UI 或弹出频率实现。本项目的本地会话规则属于静态预览行为，未请求公告接口。

页面专属切图放在 `src/assets/home/`。活动 Banner 运行时使用 `src/mock/assets/banner.webp`；大图使用 WebP。USDT 图标统一通过 `@/assets/tokens` 的 `usdtIconUrl` 引用，后续页面复用该入口。

## 公共约定

首页复用 `BasicCarousel`、`Popup`、全局工具类和主按钮皮肤；页面几何与装饰样式位于 `HomePage.scss`。Header、左侧侧边栏、菜单、多语言开关、品牌和公共按钮默认样式维持已确认的基线。

保持 `.env.development` 的 `VITE_STATIC_PAGE_MODE = 1`，预览固定已登录。首页不发起接口、RPC、钱包登录或上传请求，也不以静态数据提交业务；当前继续第 1 步静态页面开发，新增公告链路及页面视觉、交互均待用户验收。
