# 当前接口接入

当前使用真实用户统计和直推列表分页，邀请链接来自服务端 `referral_code`，与邀请页共用同源部署前缀链接辅助方法。下拉刷新等待用户资料与列表完成。

团队与个人业绩下方、直推成员列表上方展示团队激活卡统计。直接读取用户信息的 `team_cards`，保留服务端完整 `name`，`holder_count` 为不含本人的团队持有人数，`num` 为团队持有总张数，零值正常展示；不额外请求个人卡库存或用直推分页推算。下拉刷新沿用同一次用户信息请求更新这些数据。

团队统计只固定 `ACTIVATION_CARD_COVERS` 中的三个封面，加载中或无数据时也保留三张卡。沿用接口列表顺序读取 `team_cards` 的完整 `name`、`holder_count`、`num`，不写死卡名，也不按本地名称过滤接口数据；名称或统计缺失均显示 `--`，缺失统计不附单位。接口正常返回时完整展示对应真实数据，实际 `0` 保留。

每张为独立横向白卡，复用 `app-card`，内边距上下 20px、左右 30px，卡面为 80×80px，卡间距 12px。完整卡名及统计标签允许随翻译自然换行，卡片高度随内容增高，数字与单位保持整体；统计标题、标签和单位复用多语言词库。

团队页不显示页内加载失败或重试按钮。缺失的统计、业绩和邀请链接显示 `--`，实际零值保留；直推成员列表在加载结束且无数据时使用共享 `Empty`。下拉刷新仍可重新加载，直推分页失败保留已有记录并通过“加载更多”重试失败页。

测试由开发者负责。完整接口映射见项目 `docs/api/README.md`。下方为保留的历史静态设计/资源记录，其中 mock 行为不再用于当前页面。
