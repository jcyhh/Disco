# BusinessPageHero

资产、团队与购买激活卡页面共用的业务横幅，750px 设计基准下最小高 240px、圆角 20px、文案内边距 30px。`imageUrl` 传入本地图片，`title`、`subtitle` 由页面翻译后传入。

背景使用 `cover`；遮罩复用既有设计中的 SVG，保持 435×240 根尺寸。长译文换行时横幅自然增高，不遮挡后续内容。该组件只处理业务区横幅，不包含公共 Header 或导航。

`overlayUrl` 可选，默认保留现有公共遮罩；传 `null` 表示该设计无需遮罩。购买页导出的遮罩为空图层，因此传 `null`，不影响其他页面。
